读英文技术文档时，难点有时只是一小段话：`stores` 在这里是名词还是动词，`it` 指哪个对象，`before` 要求哪一步先做。查到一个中文词义后，还要回到原句，才能确认自己理解了操作顺序。

**WordTap 是一个开源英语阅读与文章跟打工具。** 把英文正文粘贴进去，可以点词查看中文释义、听发音，再用同一段材料逐句输入练习。对于需要读 README、API 说明和英文报错的开发者，这提供了一种从手头材料开始练英语的方式。

本文用两句原创的缓存说明演示完整流程。无需注册，基础阅读、ECDICT 查词和文章跟打不需要安装额外服务。

**[打开 WordTap](https://wordtap.cn/)** · [GitHub 源码](https://github.com/hawkhai/wordtap.cn)

## 先看一遍操作

这是一段由五张真实操作截图组成的 20 秒步骤动图，无音轨。截图采自 2026-10-10 官网本地构建；线上更新前，个别入口布局可能略有区别。下面的静态截图和文字可以逐步对照。

## 粘贴一小段英文

打开网站，在“输入或粘贴文章”区域输入这两句：

```text
The cache stores recent responses. Clear it before you retry the request.
```

这是本文编写的示例，不是某个框架的官方指令。先不用看译文，试着找出两个信息：什么保存了最近的响应？重试请求之前要先做什么？

输入后点击下方“点词阅读”区域，就会看到可点击的英文单词。先从两句开始，可以把注意力放在理解和操作上；之后再换成自己正在读的文档段落。

## 查一个词，再读完整句子

点击第一句中的 `cache`。原词附近和左侧会显示词典释义，这次返回的词条里包括“高速缓冲存储器”。结合这段话，可以把它理解成“缓存”。

![WordTap 点词查释义：cache 的词典解释与原句同时可见]({{ site.baseurl }}/assets/wordtap/2026-10-10/02-lookup.jpg)

继续看原文：

| 英文片段 | 在这里怎样理解 |
| --- | --- |
| The cache stores recent responses. | 缓存保存最近的响应。`stores` 在这里是动词“保存”。 |
| Clear it | 清除它，`it` 指前一句的缓存。 |
| before you retry the request | 在你重试这个请求之前，`before` 给出了先后顺序。 |

连起来就是：**缓存保存最近的响应。在重试请求之前，先清除缓存。** 这里练习的是理解句意，不执行清理操作。

词典列出多个意思，并不代表每个意思都适合当前句子。遇到项目自己定义的术语，仍要查原文里的定义。点击单词会尝试播放发音，也可以用句末入口听整句；语音能否播放取决于设备、浏览器和所选服务。

## 把刚读懂的句子打出来

点击“文章跟打”，在“在这里跟打”输入框键入第一句。输入正确后，按 Enter 或点击“下一句”。

可以做一个小实验：把 `responses` 最后一个字母故意写成 `x`。界面会标出对应位置，并提示应该输入 `s`。

![把 responses 写成 responsex 后，跟打界面显示具体字母错误]({{ site.baseurl }}/assets/wordtap/2026-10-10/03-typing-error.jpg)

改对后继续输入第二句：

```text
Clear it before you retry the request.
```

正确后点击“完成练习”，就能看到两句全部完成，也可以重新练习。演示关闭了“输入后自动朗读下一个单词”；如果希望边打边听，可以自行打开。

**这里的校验只针对英文字母，忽略大小写、空格和标点。** 适合拿自然语言句子练习输入；不要用它检查代码、Shell 命令或 API 地址是否正确。

## 确认读懂，而不只是输入完成

![WordTap 两句跟打完成，可以重练或返回阅读]({{ site.baseurl }}/assets/wordtap/2026-10-10/05-completed.jpg)

完成提示说明这次输入练习结束了。再离开原文问自己：`it` 指什么？清除缓存和重试请求，哪一个先发生？如果答不出来，就返回原文再读一次。

跟打不会替你判断技术概念是否理解正确。这套流程的用处是让阅读、查词和输入围绕同一小段材料展开，而不是把查过的词留在另一个窗口里。

## 下次继续，以及数据保存在哪里

文章会出现在“保存过的文章”列表里。下次使用同一个浏览器打开同一站点，可以恢复最近文章；重新进入跟打，可以继续草稿或查看完成进度。查过的词可以在“我的单词”里查看。

记录保存在本机浏览器，不会自动跨设备同步。更换设备或清理浏览器数据前，可以在“考试学习”页使用“导出学习数据”，再到另一设备导入。“我的单词”里的单词导出只导出单词，不包含文章与跟打进度。

本文截图所用的官网版本可以备份单词、考试记录和跟打进度，但尚未包含“保存过的文章”列表，换设备时请另存原文。公开仓库已支持连同文章一起备份；在官网同步前，不要把两个版本的导出范围视为相同。导入后先核对文章和进度，再清理旧设备数据。

本地保存也不意味着全部离线。首次加载词典等资源需要网络，在线查词或部分语音服务会处理对应的单词或文本。浏览器语音可以用于基础听读，可选 Windows Gateway 提供其他语音能力；这一篇教程不依赖它。

## 从这两句，换成你今天遇到的文档

可以选一个安装步骤、一段 API 参数说明，或者一段报错解释，取其中 2–5 句连贯正文。保留条件、代词和前后句，先说出大意，再查影响理解的词，最后跟打其中一两句。

下一次仍然从实际遇到的材料开始。英文技术文档阅读、点词查词和文章跟打，就能围绕同一个问题连续做完。
