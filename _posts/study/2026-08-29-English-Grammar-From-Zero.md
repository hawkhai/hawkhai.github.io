英语语法研究的核心只有一件事：**单词怎样组合，才能把“谁、做什么、怎么样、在何时何地”说清楚。**

零基础不必一次背完所有术语。先找到句子的主语和谓语，再学习怎样补充对象、状态、时间、原因和条件。本文只保留最常用的主线，可当作入门地图和复习清单。

## 一、先看懂句子的层次

英语表达由小到大分为四层：

| 层次 | 含义 | 例子 |
| --- | --- | --- |
| 单词 | 最小单位 | `student`、`read` |
| 短语 | 一组词，没有完整的主谓结构 | `in the room` |
| 从句 | 内部有自己的主语和谓语 | `when he arrived` |
| 句子 | 能独立表达完整意思 | `The class began.` |

```text
Small birds fly in the sky when spring comes.
春天到来时，小鸟在天空中飞。
```

- `Small birds`：名词短语，作主语。
- `fly`：谓语。
- `in the sky`：介词短语，作地点状语。
- `when spring comes`：时间状语从句。

词类表示一个词通常是什么，句子成分表示它在当前句子里做什么。两者不要混淆。

## 二、常用词类与句子成分

### 1. 八类常用词

| 词类 | 作用 | 例子 |
| --- | --- | --- |
| 名词 | 人、事、物、概念 | `teacher`、`water` |
| 代词 | 代替名词 | `I`、`she`、`it` |
| 动词 | 动作或状态 | `run`、`know`、`be` |
| 形容词 | 修饰名词，说明“什么样” | `a quiet room` |
| 副词 | 修饰动作、性质或整句 | `run quickly`、`very cold` |
| 介词 | 表示时间、地点等关系 | `in`、`on`、`with` |
| 连词 | 连接词、短语或句子 | `and`、`but`、`because` |
| 限定词 | 限定名词范围 | `a`、`the`、`my`、`some` |

一个词可能属于不同词类，要根据位置判断：

```text
The light is on.        light：名词，灯
This bag is light.      light：形容词，轻的
Please light the fire.  light：动词，点燃
```

### 2. 七个核心成分

| 成分 | 回答的问题 | 例子 |
| --- | --- | --- |
| 主语 S | 谁或什么？ | `Tom` smiles. |
| 谓语 V | 做什么、是什么状态？ | Tom `smiles`. |
| 宾语 O | 动作作用于谁或什么？ | I like `music`. |
| 表语 P | 主语是谁、怎么样？ | She is `happy`. |
| 定语 | 哪一个、什么样的名词？ | a `red` apple |
| 状语 | 何时、何地、怎样、为什么？ | He spoke `slowly`. |
| 补语 C | 对主语或宾语补充什么？ | They call him `Jack`. |

判断时先找谓语，再找主语，最后看动词后需要宾语、表语还是补语。

## 三、五个基本句型

再长的简单句，主干大多属于下面五种：

| 句型 | 例句 | 含义 |
| --- | --- | --- |
| S + V | `Birds fly.` | 鸟飞。 |
| S + V + O | `I love music.` | 我喜欢音乐。 |
| S + V + P | `She is patient.` | 她很有耐心。 |
| S + V + IO + DO | `Dad bought me a bike.` | 爸爸给我买了一辆自行车。 |
| S + V + O + C | `We found the room empty.` | 我们发现房间是空的。 |

注意两个容易混淆的地方：

```text
I go to school every day.
```

主干是 `I go`。`to school` 是地点状语，`every day` 是时间状语，不是动词 `go` 的直接宾语。

```text
There is a book on the desk.
```

`There be + 名词 + 地点` 表示“某处有某物”。`be` 与后面的名词保持单复数一致：

```text
There is a problem.
There are two problems.
```

## 四、名词短语：把“人和物”说准确

### 1. 可数、不可数与复数

- 可数名词可以数：`a book`、`two books`。
- 不可数名词通常不直接加复数：`water`、`information`、`advice`。
- 可数名词单数前通常要有限定词：`a book`、`the book`、`my book`。

常见复数：

```text
book → books
box → boxes
city → cities
child → children
```

### 2. 冠词

- `a/an`：泛指一个，首次提到。`a book`、`an apple`。
- `the`：特指双方都知道的对象，或前文已提到的对象。
- 零冠词：泛指复数或不可数概念时常不用冠词，如 `Books are useful.`。

### 3. 代词

| 主格 | 宾格 | 形容词性物主代词 | 名词性物主代词 |
| --- | --- | --- | --- |
| I | me | my | mine |
| you | you | your | yours |
| he | him | his | his |
| she | her | her | hers |
| it | it | its | — |
| we | us | our | ours |
| they | them | their | theirs |

主格常作主语，宾格放在动词或介词后：

```text
She likes him.
This gift is for her.
```

## 五、动词、否定与疑问

### 1. 动词的基本形式

| 名称 | work | write | 用途 |
| --- | --- | --- | --- |
| 原形 | work | write | 情态动词和 `do` 后 |
| 第三人称单数 | works | writes | 一般现在时 |
| 过去式 | worked | wrote | 一般过去时 |
| 过去分词 | worked | written | 完成时、被动语态 |
| -ing 形式 | working | writing | 进行时、非谓语 |

常见不规则变化要单独记：

```text
go—went—gone
see—saw—seen
take—took—taken
```

### 2. be、do、have

| 助动词 | 主要作用 | 例子 |
| --- | --- | --- |
| `be` | 进行时、被动语态 | `is reading`、`was built` |
| `do` | 一般时的否定和疑问 | `doesn't know`、`Did you go?` |
| `have` | 完成时 | `has finished` |

`do/does/did` 后必须用动词原形：

```text
Does she like it?   ✓
Did he go home?     ✓
```

### 3. 否定和疑问的通用方法

句中有 `be`、助动词或情态动词时，直接在其后加 `not`；一般疑问句把它移到主语前。

```text
She is working. → She is not working. → Is she working?
He can swim.    → He cannot swim.      → Can he swim?
```

句中只有普通动词时，用 `do/does/did`：

```text
She likes tea. → She doesn't like tea. → Does she like tea?
```

特殊疑问句通常是：

```text
疑问词 + 一般疑问句语序
Where does she live?
```

但疑问词本身作主语时不倒装：

```text
Who called you?
```

## 六、最常用的时态

时态可以理解为“时间 + 动作状态”。入门先掌握下面八种：

| 时态 | 结构 | 主要用途 | 例句 |
| --- | --- | --- | --- |
| 一般现在时 | do/does | 习惯、事实 | `She walks to work.` |
| 现在进行时 | am/is/are doing | 此刻正在发生 | `She is reading.` |
| 一般过去时 | did | 过去发生并结束 | `She left yesterday.` |
| 过去进行时 | was/were doing | 过去某时正在发生 | `She was reading at eight.` |
| 一般将来时 | will do / be going to do | 将来、打算 | `She will return.` |
| 现在完成时 | have/has done | 过去影响现在，或持续至今 | `She has finished.` |
| 过去完成时 | had done | 过去某时之前已完成 | `She had left before I arrived.` |
| 现在完成进行时 | have/has been doing | 从过去持续至今，强调过程 | `She has been studying for two hours.` |

最容易混淆的是一般过去时和现在完成时：

```text
I saw the film yesterday.  有明确的过去时间，事情已结束。
I have seen the film.      强调现在已有“看过”的经历。
```

时间和条件状语从句谈将来时，常用一般现在时：

```text
If it rains tomorrow, we will stay home.
When he arrives, I will call you.
```

## 七、语态与情态动词

### 1. 被动语态

主动句强调谁做，被动句强调谁承受动作。

```text
主动：People built the bridge in 1990.
被动：The bridge was built in 1990.
```

被动语态的核心是：

```text
be + 过去分词
```

`be` 负责时态变化：

```text
is cleaned          一般现在时被动
was cleaned         一般过去时被动
is being cleaned    现在进行时被动
has been cleaned    现在完成时被动
will be cleaned     一般将来时被动
```

### 2. 情态动词

情态动词后接动词原形，没有第三人称单数变化。

| 情态动词 | 常见含义 |
| --- | --- |
| `can/could` | 能力、许可、可能 |
| `may/might` | 许可、可能 |
| `must` | 必须；强烈推测 |
| `should` | 应该、建议 |
| `will/would` | 意愿、将来、礼貌请求 |

```text
She can swim.
You should rest.
It might rain.
```

## 八、形容词、副词、比较与介词

### 1. 形容词和副词

形容词主要修饰名词或作表语；副词主要修饰动词、形容词、副词或整句。

```text
She is a careful driver.
She drives carefully.
```

`-ing` 形容词通常描述事物令人产生的感受，`-ed` 形容词描述人的感受：

```text
The film is boring.  电影令人无聊。
I am bored.          我感到无聊。
```

比较级常用 `-er/more`，最高级常用 `-est/most`：

```text
Tom is taller than Jack.
This is the most useful book here.
```

### 2. 高频介词

| 关系 | 用法 |
| --- | --- |
| 时间 `at` | 时刻：`at 8:00` |
| 时间 `on` | 日期、具体某天：`on Monday` |
| 时间 `in` | 月、年、较长时段：`in August` |
| 地点 `at` | 一个点：`at the station` |
| 地点 `on` | 表面：`on the table` |
| 地点 `in` | 内部或范围：`in the room` |
| `for` | 持续多久：`for three years` |
| `since` | 从何时开始：`since 2020` |
| `by` | 不迟于某时 |
| `until` | 一直持续到某时 |

介词后接名词、代词宾格或动名词：

```text
with her
before dinner
look forward to meeting you
```

## 九、非谓语动词

一个简单句通常只有一组承担时态的谓语。其他动词若不另起从句，就要变成非谓语形式。

| 形式 | 常见含义 | 例子 |
| --- | --- | --- |
| `to do` | 目的、将来、一次性动作 | `I want to leave.` |
| `doing` | 过程、习惯、主动 | `I enjoy reading.` |
| `done` | 完成、被动 | `the books written by him` |

```text
I went there to see her.          表目的
Reading every day is useful.      动名词作主语
The girl standing by the door is my sister.  主动、进行
The bridge built in 1990 is old.  被动、完成
```

常见搭配：

- `want/hope/decide/plan + to do`
- `enjoy/finish/avoid/mind + doing`
- `ask/tell/want + somebody + to do`
- 介词后用 `doing`

## 十、三大从句

从句内部有自己的主语和谓语，但整体在大句子里充当一个成分。

| 从句 | 整体作用 | 例子 |
| --- | --- | --- |
| 名词性从句 | 相当于名词 | `I know that he is right.` |
| 定语从句 | 修饰名词 | `The book that you gave me is useful.` |
| 状语从句 | 说明时间、原因、条件等 | `I stayed home because it rained.` |

### 1. 名词性从句

名词性从句可以作主语、宾语或表语。最重要的规则是使用**陈述语序**：

```text
I don't know where he is.      ✓
I don't know where is he.      ×
```

常见引导词：

- `that`：只连接，不在从句中作成分。
- `whether/if`：是否。
- `what/who/which/when/where/why/how`：本身带有意义，并常在从句中作成分。

### 2. 定语从句

定语从句跟在名词后，说明“哪一个”。

```text
The girl who is singing is my sister.
This is the book that I bought yesterday.
```

选择关系词时看先行词，也看从句缺什么：

| 关系词 | 常见用法 |
| --- | --- |
| `who/whom` | 指人 |
| `which` | 指物 |
| `that` | 指人或物，常用于限制性从句 |
| `whose` | 表示“谁的” |
| `when/where/why` | 在从句中作时间、地点、原因状语 |

### 3. 状语从句

| 关系 | 常见连词 | 例子 |
| --- | --- | --- |
| 时间 | `when`、`while`、`before`、`after` | `Call me when you arrive.` |
| 原因 | `because`、`since` | `I left because I was tired.` |
| 条件 | `if`、`unless` | `If you try, you will improve.` |
| 让步 | `although`、`though` | `Although it rained, we left.` |
| 目的 | `so that`、`in order that` | `Speak slowly so that I can follow.` |
| 结果 | `so...that`、`such...that` | `He was so tired that he slept at once.` |

英语中通常不同时使用成对的中文式连接词：

```text
Although it rained, we left.       ✓
It rained, but we left.            ✓
Although it rained, but we left.   ×
```

## 十一、主谓一致与虚拟语气

### 1. 主谓一致

一般现在时中，第三人称单数主语后的普通动词加 `-s/-es`：

```text
I work here.
He works here.
```

判断复杂主语时先找到真正的中心词：

```text
The list of names is on the desk.
```

主语中心是单数 `list`，不是 `names`。

`either...or`、`neither...nor`、`not only...but also` 常按靠近谓语的主语决定单复数：

```text
Either you or he is right.
Either he or you are right.
```

### 2. 虚拟条件句

虚拟语气用于表达与事实相反的假设。入门记住两组即可：

```text
If I were you, I would wait.
如果我是你，我会等。（与现在相反）

If I had known, I would have helped.
如果我当时知道，我就会帮忙。（与过去相反）
```

## 十二、长句分析与易错清单

### 1. 长句分析五步法

遇到长句不要逐词翻译：

1. 圈出所有有时态的谓语动词。
2. 找每个谓语对应的主语。
3. 根据连词和关系词划分主句、从句。
4. 暂时拿掉定语、状语和插入语，只看主干。
5. 把修饰信息逐层放回去。

```text
The book that you gave me is useful because it explains grammar clearly.
```

结构是：

```text
[The book (that you gave me)] is useful [because it explains grammar clearly].
```

- 主句：`The book is useful.`
- `that you gave me`：定语从句，修饰 `book`。
- `because...`：原因状语从句。

### 2. 十个高频错误

```text
I very happy.                   ×  I am very happy.              ✓
I want learn English.           ×  I want to learn English.      ✓
He like coffee.                 ×  He likes coffee.              ✓
Does she likes it?              ×  Does she like it?             ✓
He runs quick.                  ×  He runs quickly.              ✓
I bought book.                  ×  I bought a book.              ✓
This is for she.                ×  This is for her.              ✓
I don't know where is he.       ×  I don't know where he is.     ✓
Because I was tired, so I left. ×  Because I was tired, I left.  ✓
I very like it.                 ×  I like it very much.          ✓
```

## 十三、核心结构速查

| 想表达什么 | 核心结构 |
| --- | --- |
| 主语做动作 | S + V (+ O) |
| 主语是什么、怎么样 | S + 系动词 + P |
| 某处有某物 | There + be + 名词 + 地点 |
| 正在做 | be + doing |
| 已经做 | have + done |
| 被做 | be + done |
| 能、必须、应该做 | 情态动词 + do |
| 想做 | want + to do |
| 喜欢做 | enjoy + doing |
| 把一句话当名词 | 名词性从句，使用陈述语序 |
| 用一句话修饰名词 | 先行词 + 关系词 + 定语从句 |
| 表达时间、原因、条件 | 从属连词 + 状语从句 |
| 与现在事实相反 | If + 一般过去时，would + do |
| 与过去事实相反 | If + had done，would have done |

## 十四、学习顺序

建议按四轮推进：

1. **句子骨架**：词类、句子成分、五个基本句型、`be/do/have`。
2. **时间表达**：一般现在、现在进行、一般过去、一般将来、现在完成。
3. **准确扩展**：名词短语、冠词、代词、形容词、副词、介词。
4. **复杂表达**：被动语态、非谓语动词和三大从句。

每天选一个句子做一次变形，比孤立背术语更有效：

```text
She reads books.                         肯定句
She doesn't read books.                  否定句
Does she read books?                     一般疑问句
What does she read?                      特殊疑问句
She read a book yesterday.               改变时态
The quiet girl read a book carefully.    添加修饰语
She read a book that I recommended.      添加从句
```

语法名称只是给不同结构起的名字。真正重要的是：**先找主语和谓语，再判断其他部分在修饰谁、补充什么。** 每学一个结构，都用“看懂公式、拆解例句、自己造句”完成闭环。
